# Curve Lab submission draft

Prepared October 1, 2026 Pacific. Local review copy; not submitted.

## Form-ready project description

Curve Lab helps launchpad builders choose a Meteora Dynamic Bonding Curve using
reproducible experiments. Set the SOL needed to graduate, the price range, and
the base fee. Compare designs against identical synthetic orders or the
recorded buys from a verified Solana mainnet launch.

The engine uses Meteora's DBC SDK math and carries virtual pool state through
each trade. It reports graduation timing, price progression, combined partner
and creator DBC fee value, partial-fill returns, and demand arriving after
migration. Each stored history must pass a reserve-continuity check and exact
replay before admission. The demo snapshot reproduces all 493 swaps across
three stored histories, with one launch supported by the current designer.

The working preset library lets builders save, fork, search, export, and import
complete experiments. It includes three free synthetic comparisons and a
portable example backed by the reference launch. Files capture simulation
inputs; they are not deployment-ready SDK configurations.

Current scope is the DBC phase. Comparisons hold buy orders fixed, omit sells,
and rebuild alternatives using standard supply-allocation defaults. Exact
verification separately includes both buys and sells. Post-migration DAMM
trading, dynamic fees, shared paid distribution, and wallet execution are
future work. Tokenized-equity launches are a prospective use case, not a
validated dataset or a claim about fundamental value.

## Integration and implementation

- Meteora DBC SDK: curve construction, swap quotes, graduation, partial fills.
- Solana mainnet event and account decoding, including Token-2022 variants.
- Offline fixtures with reserve-chain repair and exact integer replay.
- Next.js comparison UI, bounded server simulation API, local preset storage.
- Free public-RPC collector with a process lock and quarantine for rejected data.

builders to reproduce a launch, vary one assumption, and explain what they
would need to trust a deployment configuration. Measure completed trials and
specific feature requests. Shared team libraries and paid curated presets are
possible later products, subject to evidence of demand. No pricing, market-size
estimate, partnership, or adoption claim is presented as established fact.
